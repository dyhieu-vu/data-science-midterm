Sources, methods & limits

Data sources

Clean program snapshot: data/processed/programs_clean.csv. Attribute-level official evidence: data/processed/official_attribute_evidence.csv, requiring verified status, source URL and excerpt for attribute charts.

Collection method

Records were assembled from official university/admissions pages. The dashboard reports existing collection statuses; it does not retry sources or re-verify them.

Geographic scope

All current program records carry country=Vietnam. A foreign awarding partner is not treated as an international delivery location. No coordinates or international-country comparison are available.

Data treatment

Missing values remain missing. Duration intervals are not reduced to a scalar. Credit systems stay separate. Course lists remain JSON arrays and are treated as potentially partial. Program names and IDs are not used as numeric measures.

Uncertainty

Tuition is missing for all records. Confirmed curriculum text is missing; five records have course-list evidence only. Most attributes have small evidenced subsets. This snapshot is descriptive and not representative.

Evidence references

Generated from the current project CSV snapshot. No fabricated values, imputation, credit conversion or source re-verification.
